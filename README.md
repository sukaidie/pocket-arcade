# ✳ 口袋游乐场 · Pocket Arcade

中文小游戏合集：俄罗斯方块、熄灯挑战、记忆翻牌、数独。所有游戏进入前填写昵称，自动填入上次昵称。

- 俄罗斯方块：七袋随机方块、旋转、落点预览、消行加速、暂停。方向键操作，空格落到底，P 暂停；支持手机按钮。最高分显示玩家名字。
- 数独：随机变换唯一解题目，支持数字键、擦除、笔记与重复冲突提示。完成后记录最快用时和玩家名字。
- 熄灯挑战：记录通关最少步数，每局保证可解。
- 记忆翻牌：记录通关最少翻牌次数。

纪录仅在当前浏览器保存，同分保留原纪录保持者。

纯 HTML / CSS / JavaScript，无构建依赖。运行 `python3 -m http.server 8080` 后访问 http://localhost:8080；`npm test` 验证核心逻辑。推送 main 后由 GitHub Actions 自动测试并发布至 GitHub Pages。
