# ✳ 口袋游乐场 · Pocket Arcade

六款中文小游戏：扫雷、熄灯挑战、记忆翻牌、数独、五子棋、21点。所有游戏进入前填写昵称，成绩保存在当前浏览器并显示玩家名字，同分保留原纪录保持者。

- 扫雷：9×9、10 颗雷，首次点击及周围安全；支持右键或手机插旗模式，记录最快通关时间。
- 数独：唯一解题目、笔记、冲突提示、相同数字高亮，记录最快通关时间。
- 五子棋：15×15 自由规则，无禁手；人机对战，电脑会优先获胜和防守；记录玩家获胜的最少落子次数。
- 21点：与庄家对局，支持要牌、停牌和自动结算。A 自动计为 1 或 11，J/Q/K 计 10，天生 21 点优先。庄家不足 17 点要牌，达到 17 点（含软 17）停牌；记录最佳连胜与玩家名字，平局保留连胜。每局重新洗牌。
- 熄灯挑战：记录通关最少步数，每局保证可解。
- 记忆翻牌：记录通关最少翻牌次数。

纯 HTML / CSS / JavaScript，无构建依赖。运行 `python3 -m http.server 8080` 后访问 http://localhost:8080；`npm test` 验证核心逻辑。推送 main 后由 GitHub Actions 自动测试并发布至 GitHub Pages。
