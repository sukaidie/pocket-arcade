# ✳ 口袋游乐场 · Pocket Arcade

中文小游戏合集：打地鼠、熄灯挑战、记忆翻牌、井字棋。

所有游戏进入前填写昵称，自动填入上次昵称。打地鼠记录最高分；熄灯挑战记录通关最少步数；记忆翻牌记录通关最少翻牌次数。纪录显示玩家名字，同分保留原纪录保持者。成绩仅保存在当前浏览器。

打地鼠：点击开始，30 秒内点击或用数字 1—9 命中地鼠。熄灯挑战：点击切换自身和上下左右邻灯，全部熄灭即通关，每局保证可解。

纯 HTML / CSS / JavaScript，无构建依赖。运行 `python3 -m http.server 8080` 后访问 http://localhost:8080；`npm test` 验证核心逻辑。推送 main 后由 GitHub Actions 自动测试、发布至 GitHub Pages。
