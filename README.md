# ✳ 口袋游乐场 · Pocket Arcade

六款中文小游戏：扫雷、熄灯挑战、记忆翻牌、数独、五子棋、21点。所有游戏进入前填写昵称，成绩保存在当前浏览器并显示玩家名字，同分保留原纪录保持者。

- 扫雷：9×9、10 颗雷，首次点击及周围安全；支持右键或手机插旗模式，记录最快通关时间。
- 数独：唯一解题目、笔记、冲突提示、相同数字高亮，记录最快通关时间。
- 五子棋：15×15 自由规则，无禁手；保留人机对战，新增房间码联机对战。人机模式电脑会优先获胜和防守；记录玩家获胜的最少落子次数。支持连续悔棋：每次撤回最近一轮双方落子；电脑思考中会取消待落子并撤回玩家当前这一手；终局后也可悔棋继续。
- 21点：与庄家对局，支持要牌、停牌和自动结算。A 自动计为 1 或 11，J/Q/K 计 10，天生 21 点优先。庄家不足 17 点要牌，达到 17 点（含软 17）停牌；记录最佳连胜与玩家名字，平局保留连胜。每局重新洗牌。
- 熄灯挑战：记录通关最少步数，每局保证可解。
- 记忆翻牌：记录通关最少翻牌次数。

纯 HTML / CSS / JavaScript，无构建依赖。运行 `python3 -m http.server 8080` 后访问 http://localhost:8080；`npm test` 验证核心逻辑。推送 main 后由 GitHub Actions 自动测试并发布至 GitHub Pages。

## 五子棋联机

进入五子棋后点“联机对战”，一人创建房间并分享 6 位房间码，另一人用自己的设备填写昵称、输入房间码加入。房主执黑先手，朋友执白。房间最多两人；双方保持页面打开。悔棋与重新开局需对方同意；悔棋撤回到请求者上一次落子前。双方获胜都有庆祝动画，联机成绩与人机最佳纪录分开（联机不计入人机纪录）。

页面通过本地打包的 PeerJS 1.5.5 和公共 PeerServer 建立 WebRTC 数据通道，棋步由房主校验后同步。无需账户或单独配置后端；公共信令服务或网络限制可能影响连接，页面会显示超时/断线信息并暂停落子。保持双方页面打开时可重新连接并同步房主保留的棋局，关闭或刷新页面后不保留联机身份。房主可复制带当前版本的邀请链接，双方握手时会校验联机协议版本，旧版客户端需从新链接重新打开。房间码是邀请凭证，请仅分享给一起玩的朋友。PeerJS 许可证见 `vendor/peerjs-LICENSE`。
